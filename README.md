# Biblioteca PI

Um projeto de uma interface de biblioteca digital para a disciplina de Projeto Integrador (PI) do curso de Desenvolvimento de Sistemas. O site mostra os livros populares e telas de login e cadastro.

## Tecnologias

- HTML5 para a estrutura das páginas.
- CSS3 puro para o layout, a responsividade e a alternância visual entre os temas claro e escuro.

As telas são apenas demonstrativas. Os sistemas de autenticação e busca ainda não estão implementados e não há conexão com um backend.
